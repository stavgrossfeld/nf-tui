# The nf-tui name

The code is under the MIT license. The name is not covered by that license,
and this file explains how I'd like it used.

If you distribute a fork, please give it a different name. You're welcome to
say it's based on nf-tui.

No need to ask about:

- packaging it for conda, Homebrew, Spack, or a cluster module system
- writing about it, reviewing it, or using screenshots
- saying your tool works with it or reads its output

Please ask first about:

- naming a fork or product `nf-tui`, or a name close enough to be mistaken
  for it
- suggesting that this project maintains or endorses yours

You can ask by opening an issue:
<https://github.com/stavgrossfeld/nf-tui/issues>
